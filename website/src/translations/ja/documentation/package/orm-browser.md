# Deepkit ORM Browser

```sh
npm install @deepkit/orm-browser
```

Deepkit ORM Browserは、データベースのORMスキーマを閲覧し、コンテンツを編集し、
マイグレーションの変更を確認できるWebアプリケーションです。

これは[Framework Debugger](../framework.md)の一部ですが、単体で使用することもできます。
