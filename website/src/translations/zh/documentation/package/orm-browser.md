# Deepkit ORM Browser

```sh
npm install @deepkit/orm-browser
```

Deepkit ORM Browser 是一个 Web 应用程序，可用于浏览数据库 ORM schema、编辑内容
以及查看迁移变更。

它是 [Framework Debugger](../framework.md) 的一部分，但也可以独立使用。
