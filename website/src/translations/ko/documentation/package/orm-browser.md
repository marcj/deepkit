# Deepkit ORM Browser

```sh
npm install @deepkit/orm-browser
```

Deepkit ORM Browser는 데이터베이스 ORM schema를 탐색하고, 콘텐츠를 편집하며
migration 변경 사항을 확인할 수 있는 웹 애플리케이션입니다.

이는 [Framework Debugger](../framework.md)의 일부이지만 단독으로도 사용할 수 있습니다.
